## スクリプトの使い方

各市のPDFを個別にダウンロードする場合は、対応するスクリプトを実行します。

```bash
# 例：大阪市のハザードマップをダウンロード
bash scripts/download_osaka.sh

# 例：枚方市のハザードマップをダウンロード
bash scripts/download_hirakata.sh
```

ダウンロード先は `大阪府/<市区町村名>/` に保存されます。

---

## データについて

- 各PDFは各市区町村の公式サイトで公開されているものです。
- 内容の正確性については各自治体の公式情報を参照してください。
- データは収集時点のものであり、最新情報は各自治体のウェブサイトでご確認ください。
